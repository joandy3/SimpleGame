# Space Shooter

เกมยิงยานอวกาศแนว shoot 'em up เขียนด้วย Python + **tkinter** ล้วนๆ อยู่ในไฟล์เดียว ([main.py](main.py)) ไม่ต้องติดตั้ง library เพิ่ม

เลือกยานและอาวุธที่ถนัด แล้วยิงฝ่าศัตรูที่บุกเข้ามาเป็นเวฟ ทุก 5 เวฟจะเจอบอส เล่นได้ไม่รู้จบ ยิ่งไปไกลยิ่งยาก

## การติดตั้งและเริ่มเกม

ต้องมี **Python 3.6 ขึ้นไป** (ทดสอบกับ Python 3.14 บน Windows 11)

```bash
python main.py
```

> **Linux:** ถ้าขึ้น `No module named 'tkinter'` ให้ติดตั้งก่อน เช่น `sudo apt install python3-tk`
> **Windows / macOS:** tkinter มากับตัวติดตั้ง Python จาก python.org อยู่แล้ว

## ปุ่มควบคุม

### ระหว่างเล่น

| ปุ่ม | การทำงาน |
|---|---|
| ลูกศร / `W` `A` `S` `D` | บังคับยาน |
| `Space` / `J` | ยิง (กดค้างได้) |
| `X` / `Shift` / `K` | ใช้สกิลพิเศษของยาน |
| `P` / `Esc` | พักเกม |

### หน้าเลือกยานและอาวุธ

| ปุ่ม | การทำงาน |
|---|---|
| `←` `→` | เลือกยานหรืออาวุธ |
| `↑` `↓` / `Tab` | สลับแถวยานกับแถวอาวุธ |
| `Enter` | เริ่มเกม |
| `G` | เปิดหน้า GitHub ของโปรเจกต์ |
| เมาส์ | คลิกการ์ดเพื่อเลือก คลิกปุ่ม ENTER เพื่อเริ่ม คลิกปุ่มผู้พัฒนามุมขวาบนเพื่อเปิด GitHub |

### หน้าพักเกมและหน้า Game Over

| ปุ่ม | การทำงาน |
|---|---|
| `P` / `Esc` | เล่นต่อ (ตอนพักเกม) |
| `Q` | กลับไปหน้าเลือกยาน (ตอนพักเกม) |
| `Enter` | เล่นใหม่ด้วยยานและอาวุธเดิม (ตอน Game Over) |
| `C` | กลับไปเปลี่ยนยานหรืออาวุธ (ตอน Game Over) |
| `Esc` | ออกจากเกม (ตอน Game Over และหน้าเลือกยาน) |

ถ้าสลับไปหน้าต่างอื่นระหว่างเล่น เกมจะพักให้อัตโนมัติ

## ยาน

ยานแต่ละลำมีความเร็ว จำนวนชีวิต ขนาดตัว (จุดที่โดนยิง) พลังยิง และสกิลพิเศษต่างกัน
สกิลจะชาร์จเองตามเวลา ดูได้จากหลอดมุมซ้ายล่าง พอเต็มจะขึ้นว่า `READY`

| ยาน | ความเร็ว | ชีวิต | พลังยิง | สกิล | ชาร์จ |
|---|---|---|---|---|---|
| **FALCON** ยานจู่โจมความเร็วสูง | เร็วมาก | 2 | 90% | **DASH**: พุ่งตัวไปทางที่กำลังบิน และอมตะชั่วครู่ | 2.5 วินาที |
| **NOVA** ยานรบอเนกประสงค์ | ปานกลาง | 3 | 100% | **EMP**: ล้างกระสุนศัตรูทั้งจอ และทำดาเมจศัตรูทุกตัว | 12 วินาที |
| **TITAN** ยานป้อมปราการหนัก | ช้า | 4 | 125% | **BARRIER**: โล่ 4.5 วินาที ดูดกระสุนและเผาศัตรูที่เข้าใกล้ | 14 วินาที |

FALCON ตัวเล็กที่สุดจึงหลบง่ายที่สุด ส่วน TITAN ตัวใหญ่ที่สุด

## อาวุธ

อาวุธทุกแบบอัปเกรดได้ 3 เลเวลด้วยไอเทม **P** ถ้าโดนยิงจะลดลง 1 เลเวล

| อาวุธ | ลักษณะ | ยิ่งเลเวลสูง |
|---|---|---|
| **BLASTER** ปืนเลเซอร์คู่ | ยิงตรงคู่ เสถียร ใช้ง่าย | ได้กระสุนเฉียงเพิ่ม สูงสุด 5 นัด |
| **SCATTER** ปืนลูกซองอวกาศ | กระจายเป็นวงกว้าง ระยะสั้น ยิ่งเข้าใกล้ยิ่งแรง | ได้ลูกปรายเพิ่มจาก 5 เป็น 9 ลูก และยิงไกลขึ้น |
| **PIERCER** ลำแสงทะลุทะลวง | ยิงรัวเร็ว ทะลุศัตรูได้หลายตัว แต่ดาเมจต่อนัดต่ำ | ได้ลำแสงเพิ่ม และทะลุได้มากขึ้น |
| **SEEKER** มิสไซล์นำวิถี | มิสไซล์ไล่ตามเป้าหมายเอง ยิงช้าแต่ระเบิดเป็นวงกว้าง | ยิงได้ทีละ 1 ถึง 3 ลูก |

## ไอเทม

ศัตรูมีโอกาสดรอปไอเทมเมื่อถูกทำลาย บอสดรอปทีละ 3 ชิ้น เก็บไอเทมได้ +50 คะแนนทุกครั้ง

| ไอเทม | ผล |
|---|---|
| **P** | อัปเกรดอาวุธ +1 เลเวล (ถ้าเต็มแล้วได้ +500 คะแนนแทน) |
| **R** | ยิงเร็วขึ้นเป็นเวลา 12 วินาที |
| **O** | โล่ที่กันการโดนยิงได้ 1 ครั้ง อยู่ได้ 15 วินาที |
| **E** | เติมสกิลให้เต็มทันที |
| **+** | ชีวิต +1 (มีได้สูงสุด 6) |

## ศัตรู

| ศัตรู | พฤติกรรม | คะแนน |
|---|---|---|
| สามเหลี่ยมส้ม | บินส่ายลงมา | 100 |
| หกเหลี่ยมเหลือง | บินซิกแซกเด้งกับขอบจอ (เริ่มเวฟ 2) | 160 |
| ยานแดง | ลอยค้างกลางจอแล้วเล็งยิงใส่เรา (เริ่มเวฟ 3) | 260 |
| ยานม่วงตัวใหญ่ | เลือดหนา ยิงกระจาย 3 นัด (เริ่มเวฟ 4) | 480 |
| **บอส MOTHERSHIP** | มาทุก 5 เวฟ ยิงทั้งแบบเล็งและแบบพัด พอเลือดต่ำกว่าครึ่งจะยิงถี่ขึ้น และตั้งแต่บอสตัวที่ 2 มีกระสุนหมุนวนเพิ่ม | 3000 ขึ้นไป |

ศัตรูจะเลือดหนาขึ้นทุก 4 เวฟ และกระสุนศัตรูจะเร็วขึ้นเรื่อยๆ ตามเวฟ

## การนับคะแนน

- **คอมโบ:** ทำลายศัตรูต่อเนื่องโดยเว้นช่วงไม่เกิน 2.5 วินาที จะได้ตัวคูณคะแนนเพิ่มทีละขั้นทุก 6 ตัว สูงสุด **x5** ถ้าโดนยิงคอมโบจะหายทันที
- **PERFECT WAVE:** ผ่านเวฟโดยไม่เสียชีวิตเลย ได้โบนัส 200 × หมายเลขเวฟ
- **คะแนนสูงสุด:** เกมจะบันทึกคะแนนสูงสุดไว้ แสดงที่มุมขวาล่างของหน้าเลือกยาน

## ไฟล์บันทึก

เกมจะเก็บคะแนนสูงสุด และยานกับอาวุธที่เลือกล่าสุด ไว้ที่

```
~/.space_shooter_save.json
```

(บน Windows คือ `C:\Users\<ชื่อผู้ใช้>\.space_shooter_save.json`) ถ้าต้องการรีเซ็ตคะแนน ให้ลบไฟล์นี้ทิ้ง

## ปรับแต่งเกม

ค่าต่างๆ อยู่ด้านบนของ [main.py](main.py) แก้แล้วรันใหม่ได้ทันที

| ต้องการปรับ | แก้ที่ |
|---|---|
| ความเร็ว ชีวิต พลังยิง เวลาชาร์จสกิลของยาน | `SHIPS` (`speed`, `lives`, `power`, `skill_cd` หน่วยเป็นเฟรม 60 เฟรมเท่ากับ 1 วินาที) |
| ดาเมจและความเร็วในการยิงของอาวุธ | `WEAPONS` (`dmg`, `cd` หน่วยเป็นเฟรมต่อนัด ยิ่งน้อยยิ่งยิงเร็ว) |
| เลือดและคะแนนของศัตรู | `ENEMY_SPEC` |
| โอกาสดรอปไอเทมแต่ละชนิด | `POWERUPS` (ตัวเลขตัวสุดท้ายคือน้ำหนักโอกาสดรอป) |
| จำนวนและชนิดศัตรูในแต่ละเวฟ | เมธอด `Game.next_wave` |
